# 🐍 Snake Game in Java

My first Java project! A classic Snake Game built using Java Swing.

## 🎮 How to Play
- Use Arrow Keys to move the snake - Up, Down, Left, Right
- Eat the red food to grow longer
- Don't hit the walls or yourself!
- Score increases with every food you eat

## ▶️ How to Run
1. Open SnakeGame.java in VS Code / IntelliJ
2. Click Run
3. Game window will open - Enjoy!

## 🛠️ Built With
- Java
- Java Swing (JFrame, JPanel, Timer)
- OOP Concepts
